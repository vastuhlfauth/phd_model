# EMP 2019 (Enquête mobilité des personnes), public tables

- **Source:** SDES, EMP 2019 ("Enquête mobilité des personnes"), national household travel survey; public microdata release ("Tables Définitives"), version 4 (data), version 3 (most tables' dictionary codes). `config/sources.yaml` source id `emp2019`.
- **Vintage(s):** fieldwork 2018-2019; public release December 2021, last updated November 2024.
- **Local path:** `data/raw/emp2019/emp2019-data.zip` (CSVs), `emp2019-dictionary.xlsx` (variable list per table), `emp2019-categories.pdf` (categorical code labels), `emp2019-documentation.pdf`.
- **CRS:** none (tabular microdata only; no coordinates).
- **Keys and joins:** `IDENT_IND` (person) links `K_DEPLOC` (trips), `TCM_IND_KISH_public` (the Kish-selected respondent's demographics) and `K_INDIVIDU_public` (that respondent's individual weight and commute-equipment answers). `IDENT_MEN` (household) links to `Q_MENAGE_public` (household weight and vehicle fleet). Only the Kish-selected respondent of each household has a travel diary (`K_DEPLOC`); the five tables below share that respondent universe except `TCM_MEN`/`Q_MENAGE` (household level) and `TCM_IND_public` (every household member, used for linkage tables, not demographics).
- **Encoding:** the five CSVs are Windows-1252 (French accents); DuckDB's CSV reader only accepts UTF-8/Latin-1, so `mobgrid.budget.emp2019.extract_tables` re-encodes each file to UTF-8 once, under `data/interim/emp2019/csv/`.
- **Delimiter:** `K_DEPLOC` (zip member `5. k_deploc_public_V4.csv`) is comma-separated with `"`-quoted fields; `TCM_IND_public`, `TCM_IND_KISH_public`, `K_INDIVIDU_public` and `Q_MENAGE_public` are semicolon-separated, unquoted.
- **Nulls:** the literal string `NA`, except a few categorical codes (e.g. `SITUA` for a child too young to answer) which are an empty string instead.
- **Used by:** step 11 (`mobgrid.budget.emp`), section 9.9's re-estimation.

## What the questionnaire says

**EMP 2019, §3.2.1 (PDF p. 21):** « Nous allons passer en revue les uns après les autres tous les déplacements que vous avez réalisés [mjour] dernier entre 4 heures du matin et 4 heures le jour suivant, quels que soient leur mode ou leur longueur. N'oubliez pas de mentionner vos déplacements ou vos promenades à pied. » Interviewer instruction: « N'oubliez pas de demander si la personne ne s'est pas arrêtée durant le déplacement qu'elle a déclaré. N'oubliez pas non plus les « petits déplacements » : accompagner un enfant, acheter du pain, le journal, l'essence, promener le chien. »

**ENTD 2008, §6.2.1 (PDF p. 87):** « Nous allons passer en revue tous les déplacements que vous avez réalisés [mjourdep] dernier entre 4 heures du matin et 4 heures le jour suivant. » No prompt about stops or small trips.

**Professional rounds** (ENTD §6.2.6, PDF p. 93; EMP §3.2.7, PDF p. 31): both record one trip, with the number of stops, total distance and farthest commune. EMP adds: « Décrire une tournée sans interruption prolongée. Si, par exemple, vous vous êtes arrêté pour manger, cela marque la fin d'une tournée. »

## Voyage dates and away days

The public `K_VOYAGE` dictionary lists `IDENT_IND`, `OLDDEBJ_jour`,
`OLDDEBJ_mois`, `OLDFINJ_jour`, `OLDFINJ_mois`, and `OLDVMH`. Departure and
return are given as weekday and month, not complete dates. These fields
alone do not establish a strict date interval around a described day; do
not infer an exact interval from them. The voyage trips are not part of the
described-day trip chain.

## Columns used: `Q_MENAGE_public` (one row per household)

| Column | Type | Unit | Meaning | Example |
|---|---|---|---|---|
| `IDENT_MEN` | string | — | Household identifier | `M1` |
| `JNBVEH` | int | count | Cars, light commercial vehicles (VUL) and camper vans at the household's disposal, including out-of-use vehicles | `2` |
| `JNBVHS` | int | flag | Whether the household has out-of-use vehicles (`1` yes, `2` no) | `2` |
| `JNBVPHS`, `JNBCCHS`, `JNBVULHS` | int | count | Out-of-use cars, camper vans and VUL, respectively | |

For the in-use vehicle count, subtract the out-of-use counts:
`JNBVEH - (JNBVPHS + JNBCCHS + JNBVULHS)`. The three counts are present in
the public `Q_MENAGE_public` table. A missing out-of-use count is treated as
zero when `JNBVHS = 2`. The flag is not asked when `JNBVEH = 0`, which
always gives zero in-use vehicles. For a positive total, missing out-of-use
counts otherwise leave the in-use count unknown. If a future public table lacks the three out-of-use counts, use
`JNBVEH` and report the household-weighted share with `JNBVHS = 1`.

The [questionnaire](https://www.statistiques.developpement-durable.gouv.fr/sites/default/files/2022-07/questionnaire_emp2019.pdf)
asks for `JNBVEH`: « De combien de voitures particulières, de véhicules
utilitaires légers ou de camping-cars votre ménage dispose-t-il au total ? »
The report groups the harmonised
in-use total into 0, 1 and 2+ vehicles and shows household-weighted shares
using `pond_menC`.
See [entd2008.md](./entd2008.md) for the corresponding ENTD question and
count.

## Quirks

- Trip motives use `MMOTIFDES`, except returns home or to a residence (codes 1.1-1.3), which take the trip's origin motive from `MOTPREC`, harmonised with ENTD 2008. SDES's November 2024 note describes `MOT_SEQ_COMPL` as a sequence's dominant activity, not a trip motive.
- Step 11 per-person estimates sum local, needs-scope described-day values with `POND_JOUR`, divide weekday totals by 5 (or the full-week total by 7), and divide by the full `K_INDIVIDU.pond_indC` roster. A respondent with no local trip contributes zero to the numerator but remains in the denominator.
- `mtp`'s categorical codes are stored as floats (e.g. `3.2`), so code `5.10` ("autres transports urbains et régionaux sans précision") is numerically identical to `5.1` ("autobus urbain"): DuckDB (and any other float-based reader) cannot distinguish the two. `mobgrid.budget.emp2019` groups them together, which is harmless for its vehicle mapping (both are "urban_bus").
- `K_DEPLOC` has no leg-by-leg breakdown (no separate walk-to-stop/wait/ride durations); only the trip's overall `mtp`, `DUREE` and `MDISTTOT_fin` are given. `MTEMPSMAP` (walking time within the trip) and `MTPSATTENT` (PT waiting time) are the trip's own declared terminal-leg minutes: since the 27 October 2026 decision (section 9.9), `mobgrid.budget.trip_legs.build_trip_legs`'s default `terminal_legs='declared'` uses them (replacing the car/carpool/PT/bike terminal-leg defaults of sections 9.4-9.7, falling back to those defaults where a value is missing); `terminal_legs='defaults'` keeps the former, defaults-only model for the F8 robustness sweep.
- `Q_MENAGE_public` and `TCM_IND_public` are read by `mobgrid.budget.emp2019.extract_tables`/`register_views`. `Q_MENAGE_public` supplies the in-use vehicle count for the income supplement; its columns do not enter step 11's travel-time formulas. `TCM_IND_public` is only a linkage table and is not used by those formulas.
